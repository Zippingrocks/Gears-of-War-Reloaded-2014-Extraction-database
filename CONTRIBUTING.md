# Contributing

Contributions should improve reproducibility, native-source coverage, or the clarity of known limitations.

1. Identify the exact Steam build and package scope.
2. Record native package and object identifiers.
3. Add or revise a machine-readable evidence claim.
4. Keep owned game data and generated assets external.
5. Add deterministic tests for maintained parsers and validators.
6. Run the repository validation commands in `AGENTS.md`.

Do not call a scene complete based only on visual density. Report unresolved packages, actor/component classes, mesh references, transform chains, material bindings, and excluded runtime layers.
