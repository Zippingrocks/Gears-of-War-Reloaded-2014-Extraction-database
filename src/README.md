# Maintained Source

- `reloaded_package.py`: dependency-free package-summary parser and CLI.
- `gowreloaded_static_uvstream_regression_guard.py`: fail-fast validation of decoded UE3 StaticMesh UV stream metadata.
- `gowreloaded_map_textured_staticmesh_asset_pack.py`: packages previously decoded geometry/material caches into OBJ/MTL assets outside Git.

No maintained full native map exporter is claimed yet. The packaging layer does not replace package decoding.
