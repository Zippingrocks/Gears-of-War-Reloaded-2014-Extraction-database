# Evidence Standard

Every durable conclusion must identify:

- game and platform build;
- native package or map family scope;
- claim state and confidence;
- compact evidence references;
- known limitations and excluded layers.

Allowed states are `hypothesis`, `observed`, `decoded`, `validated`, `rejected`, and `unknown`.

`validated` requires repeatable output or a deterministic source check. A prior render proves that a scene opened and rendered; it does not prove complete runtime parity. Missing source tools reduce reproducibility and must remain explicit.
